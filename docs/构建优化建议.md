## 二、优化策略

### 🔴 优先级 P0：拆分 EncodingPanel 加密算法

**问题：**
`EncodingPanel` 将所有加密算法（AES/DES/RSA/SM2/SM4/bcrypt 等）一次性导入，即使用户只用 Base64 编码也会加载全部算法库。

**方案：动态导入（Dynamic Import）**

```typescript
// 当前实现（❌ 全量导入）
import CryptoJS from 'crypto-js';
import bcrypt from 'bcryptjs';
import { sm2, sm4 } from 'sm-crypto';

// 优化后（✅ 按需导入）
async function encryptAES(text: string, key: string) {
  const { default: CryptoJS } = await import('crypto-js');
  return CryptoJS.AES.encrypt(text, key).toString();
}

async function hashBcrypt(text: string) {
  const { default: bcrypt } = await import('bcryptjs');
  return bcrypt.hash(text, 10);
}
```

**预期收益：**
- 首次加载减少 ~100KB
- 用户点击「AES 加密」时才加载 crypto-js（~40KB）
- 点击「国密算法」时才加载 sm-crypto（~30KB）

**实施步骤：**
1. 在 `src/lib/crypto/` 下创建按需加载的 wrapper：
   - `crypto-aes.ts`、`crypto-des.ts`、`crypto-sm.ts`、`crypto-hash.ts`
2. 每个 wrapper 内部用 `await import()`
3. `EncodingPanel` 改为调用这些 async 函数
4. 添加加载状态提示（「正在加载加密库...」）

---

### 🟡 优先级 P1：提取共享组件样式

**问题：**
`ui.ts` (53KB) 包含 Toast/Theme/AutoRun 等 store，但也可能打包了大量 CSS-in-JS 或重复的 Tailwind 类。

**方案：**
1. 检查 `ui-CFWRJUO2.js` 是否包含重复的 UnoCSS 原子类
2. 使用 `@unocss/preset-icons` 替代内联 SVG 图标
3. 将 Toast 组件的动画 CSS 提取到独立的 `.css` 文件

**预期收益：**
- 减少 ~10-15KB

---

### 🟡 优先级 P1：优化 HAE 规则存储

**问题：**
`hae-store` (52KB) 存储了大量正则表达式规则。

**方案：**
1. 将规则从 TypeScript 常量改为 JSON 文件（`public/rules/hae.json`）
2. 面板加载时通过 `fetch('/rules/hae.json')` 动态加载
3. 使用 LZ-String 或 fflate 压缩规则数据

**预期收益：**
- 减少 ~30KB（规则 JSON 可被浏览器缓存）

---

### 🟢 优先级 P2：代码分割策略

**当前状态：**
- 36 个面板已实现动态加载（通过 `loaders.ts`）
- Rollup 自动为每个面板生成独立 chunk ✅

**进一步优化：**
1. **共享依赖提取**：将多个面板共用的库（如 `js-yaml`）提取到独立 chunk
   ```typescript
   // vite.config.ts
   build: {
     rollupOptions: {
       output: {
         manualChunks: {
           'vendor-yaml': ['js-yaml'],
           'vendor-fflate': ['fflate'],
         }
       }
     }
   }
   ```

2. **预加载策略**：根据 `recentPanelsStore` 预加载 Top 3 面板
   ```typescript
   // App.svelte
   $effect(() => {
     const recent = $recentPanelsStore.slice(0, 3);
     recent.forEach(id => {
       const panel = panels.find(p => p.id === id);
       panel?.load(); // 触发 Promise 缓存
     });
   });
   ```

## 五、长期优化方向

1. **Tree Shaking 深度优化**
   - crypto-js 只导入使用的算法（而非整个库）
   - 示例：`import AES from 'crypto-js/aes'` 替代 `import CryptoJS from 'crypto-js'`

2. **Brotli 压缩**
   - 浏览器扩展支持 Brotli（br）压缩
   - 配置 WXT 输出 `.br` 文件，Chrome 自动解压

3. **虚拟滚动**（已列入任务 #17）
   - ResponsiveTable 处理 1000+ 行结果时，只渲染可见区域
   - 预期减少 DOM 节点 90%，提升交互流畅度

4. **Service Worker 缓存**
   - 将不常变化的面板 chunk 缓存到 SW
   - 二次打开扩展时 0 网络请求
