## 通用交互

绝大多数面板共享一套统一交互，掌握一次即可。

### 目标输入（UrlInput）

- 顶部输入框自动带入 **当前标签页 URL**，可手动改
- 聚焦时展开 **最近目标** 列表，点选即填
- 支持纯键盘操作（方向键 / Enter）；失焦自动收起，点列表项不会提前关闭

### 面板搜索

侧栏搜索框匹配维度：面板名 / 分类 / id / 中文别名 / 英文别名 / 关键词。

| 搜索词 | 命中 |
|---|---|
| 跨域 | CORS 检测 |
| cookie | Cookie 审计 |
| 若依 | RuoYi 路由 |
| fofa | 资产测绘 |
| 加密 | 编码工具 |

### 任务控制（TaskController）

接入 `TaskController` 的面板（XSS / 目录扫描 / URL 多开 / JS 归档 / Vue 路由遍历 等）提供：

- **运行 / 取消**：随时中断，UI 立即回退到非运行态
- **进度反馈**：阶段、已完成 / 总数
- **并发限流**：批量任务走 `runConcurrent` 并发池，按 hostname 限流（防 DoS）
- **旧结果保护**：快速重复启动只保留最新一次结果，旧 run 的回写被丢弃

### 结果区统一能力

- **结果工具栏（ResultToolbar）**：搜索 / 筛选 / 排序
- **导出菜单（ExportMenu）**：JSON / CSV / TXT / 复制
- **详情抽屉（DetailDrawer）**：单条结果展开详情
- **空状态 / 错误状态**：统一组件，无结果与异常的视觉一致

### 跨面板 handoff

带 `handoff` 能力的面板（信息收集 / 目录扫描 / 链接提取 / 历史档案 等）的结果可 **一键跳到关联面板** 继续分析，目标 URL 自动透传，无需复制粘贴。

## 🔵 侦察 Recon

### 🖼️ 图标识别（favicon）

- **输入**：目标 URL
- **能力**：计算站点 favicon 的多种 hash（mmh3 等），用于在测绘平台反查同源 / 同模板资产
- **输出**：hash 值（可复制）+ 测绘平台检索链接

### 🔍 信息收集（gather）

- **输入**：目标 URL
- **能力**：抓取页面 HTML + 所有 JS，提取技术栈指纹、API 接口、子域、敏感信息
- **特点**：JS 抓取走 `runConcurrent` 并发池（并发 6、可取消、URL 去重）
- **输出**：分类结果，可导出，可 handoff 到泄露扫描 / 链接提取

### 🌐 子域名（subdomain）

- **输入**：目标域名
- **能力**：子域名枚举（依赖外部测绘 API，需在 [设置](#设置) 配 key）
- **输出**：子域名列表（可导出）

### 📍 资产测绘（asset）

- **输入**：查询语法（如 `ip="1.2.3.4"`、`title="xxx"`）
- **能力**：对接 **FOFA / ZoomEye / Quake** 测绘平台
- **注意**：需在设置中填对应平台 API key；受各平台配额限制

## 🔴 扫描 Scan

### ⚡ XSS 扫描（xssscan）

内置 **两阶段主动验证引擎**，不止“发现反射”，自动“证明可利用”：

- **注入点采集**：URL 参数、表单、链接、AJAX 拦截捕获（hook fetch / XHR）、DOM Sink
- **Phase 1 反射过滤**：金丝雀 probe 快速筛掉不反射的注入点（减少 Phase 2 工作量）
- **Phase 2 Payload 矩阵**：反射点 × 5 上下文（html / attr / script / url / style）payload 逐个注入
- **回显确认 + 净化检测**：`findReflection` 找 marker 确认反射；`isSanitized` 判断是否被编码 / 转义 / 过滤 —— **反射且未净化 = 漏洞**
- **上下文感知 + 严重度分级 + 证据留存**：按上下文评估严重度，留存反射点周围文本作为证据
- **任务控制**：`TaskController` 可取消 + 进度上报 + task-center；并发池按 hostname 限流
- **输出**：漏洞判定（`reflected && !sanitized`）/ 上下文 / Payload / 证据 / 详情抽屉

### 💉 SQLi 扫描（sqliscan）

报错注入验证引擎，基线对比防误报：

- **注入点采集**：URL 参数 + 表单字段（同源页面 execInTab 采集）
- **两阶段探测**：
  - Phase 1 基线采集 —— 每点取无 payload 的正常响应
  - Phase 2 报错 payload 矩阵 —— 注入点 × payload，检测 SQL 错误特征
- **基线对比防误报** —— 仅当 payload 触发了【基线没有的】SQL 错误才确认（避免页面静态含报错文字误报）
- **DB 识别** —— MySQL / MSSQL / PostgreSQL / Oracle / SQLite（具体 DB → 高危；仅通用特征 → 中危）
- **任务控制**：`TaskController` 可取消 + 进度上报 + task-center；并发池按 hostname 限流
- **范围**：仅报错注入（无误报、无合规风险）；布尔盲注 / 时间盲注留后续阶段
- **输出**：参数 / Payload / DB 类型 / 证据 / 详情抽屉

### 🔗 CORS 检测（cors）

- **输入**：目标 URL
- **能力**：检测跨域配置错误（Origin 反射、`null`、通配 + 凭据等）
- **输出**：风险等级 + 响应头详情

### 🛡️ 安全头（headers）

- **输入**：目标 URL
- **能力**：审计安全响应头（CSP / HSTS / X-Frame-Options / X-Content-Type-Options 等）
- **输出**：缺失项 + 配置建议

### 🔥 WAF 指纹（waf）

- **输入**：目标 URL
- **能力**：发送探测请求，识别 Web 应用防火墙（Cloudflare / 阿里云 / 安全狗 等）
- **输出**：WAF 类型 + 置信度

### ↗️ 重定向（redirect）

- **输入**：目标 URL
- **能力**：追踪完整重定向链；检测开放重定向（Open Redirect）
- **输出**：跳转链（状态码 + URL）

### 📂 目录扫描（fuzz）

- **输入**：目标 URL + 字典
- **能力**：目录 / 路径字典扫描
- **任务控制**：`TaskController` + 并发池，可暂停 / 取消，按 hostname 限流
- **输出**：有效路径（状态码 / 长度），可 handoff 到源码加载

### ◈ GraphQL（graphql）

- **输入**：目标 URL / GraphQL 端点
- **能力**：端点探测 + 内省（Introspection）查询
- **输出**：Schema / 类型 / 字段

### 🍪 Cookie 审计（cookie-audit）

- **输入**：目标域名
- **能力**：检查 Cookie 的 Secure / HttpOnly / SameSite / 过期等属性
- **注意**：使用 `cookies` 权限，仅限用户显式填入的 domain
- **输出**：属性合规性 + 风险

### 👃 网站嗅探（sniff）

- **输入**：目标 URL
- **能力**：CMS / 框架 / 服务器 / 技术栈指纹识别（签名预编译）
- **输出**：技术栈清单

### 🔓 泄露扫描（leakscan）

- **输入**：目标 URL / 文本
- **能力**：**90 条规则**扫描敏感信息（AWS Key / GitHub Token / 私钥 PEM / JWT / 数据库连接串 / 邮箱 / 内网 IP 等）
- **特点**：低熵过滤（排除占位符 / 重复字符）、Luhn 校验（信用卡 / API Key）、placeholder 过滤、去重
- **输出**：命中的敏感信息（类型 + 严重度），报告自动脱敏

### 🎨 HAE 规则（hae）

- **输入**：目标 URL / 文本
- **能力**：用户自定义正则规则高亮提取（对齐 v5 的 HaE YAML 管理）
- **配置**：在选项页用 YAML 编辑自定义规则组（含 group / name / f_regex / s_regex / color / scope / engine）；支持正则合法性预校验
- **输出**：按规则组着色的高亮结果

## 🟠 利用 Exploit

### 🔤 编码工具（encoding）

- **能力**：编解码 + 哈希 + 加解密一站式
  - 编码：Base64 / URL / Hex / HTML / Unicode
  - 哈希：MD5 / SHA-1 / SHA-256 / SHA-512 / SM3 / HMAC
  - 加密：AES（5 模式 × 3 keySize）/ DES / 3DES / RC4 / **SM2** / **SM4** / RSA-OAEP / Bcrypt
- **操作**：左输入右输出，自动识别编码（部分）

### 💊 Payload（payload）

- **能力**：6 大类 Payload 参考库
  - **XSS** / **SQLi** / **LFI** / **反弹 Shell** / **Webshell** / **命令参考**
- **SQLi 动态生成**：填列数（N）+ 目标表名，自动生成 `ORDER BY` 探测、`UNION SELECT` 列数、版本 / 表名 / 列名 / 数据提取、报错 / 延时 / 认证绕过等 Payload
- **反弹 Shell**：填监听 IP + 端口，复制时自动替换 `{ip}` / `{port}` 占位
- **操作**：点 Payload 即复制

### 🎭 请求伪造（spoof）

- **能力**：通过 `declarativeNetRequest` 改写请求头
  - User-Agent 伪造
  - XFF / Referer / 自定义请求头
- **特点**：MV3 合规（DNR，非 webRequest）；规则持久化，恢复时按存储状态重建
- **注意**：受 `host_permissions` 约束，仅作用于指定 origin

### ⚙️ JS 控制（jsctrl）

- **能力**：通过 DNR 阻断页面指定 JS 资源加载；或 hook 关键函数（fetch / XHR / eval 等）
- **用途**：绕过前端反调试、移除指纹脚本、观察关键调用
- **注意**：阻断规则可随时关闭恢复

## 🟢 框架 Framework

> 框架分析面板通过 **MAIN world 注入**直接访问页面框架运行时，能力远超“正则提取”。

### 🟢 Vue 分析（vue）

- **能力**：
  - **持久拦截**：hook `fetch` / `XMLHttpRequest`，捕获页面 AJAX（用于分析接口、Token 流转）
  - **路由遍历**：枚举 Vue Router 全部路由（含隐藏路由），自动遍历并报告可达性
  - **Store 探测**：读取 Vuex / Pinia 状态树
- **任务控制**：路由遍历接入 `TaskController`，可取消
- **卸载安全**：关闭拦截或卸载面板时自动 `_restore()` 还原原生 fetch / XHR，无残留 hook

### ⚛️ React 分析（react）

- **能力**：探测 Redux / Zustand / Context / Hooks 状态；组件树信息

### 🅰️ Angular 分析（angular）

- **能力**：探测 Service / 依赖注入 / Ngrx 状态；路由配置

### 🔶 Svelte 分析（svelte）

- **能力**：探测 Svelte store / rune（`$state` / `$derived`）状态

### 📁 RuoYi 路由（ruoyi）

- **能力**：**若依（RuoYi）后台框架专项**
  - 批量抓取页面 JS，正则提取后端路由 / 接口（走 `runConcurrent` 并发池，跨 URL 去重）
  - 枚举隐藏功能页 / 越权接口
- **输出**：路由清单（可导出），可 handoff 到目录扫描 / URL 多开

### 🗺️ Source Map（sourcemap）

- **能力**：
  - 提取 inline（base64 / url-encoded）与 external source map
  - 还原原始源码（目录结构）
  - 在还原源码中扫描敏感信息 / 后端端点
- **输出**：源码树（可导出）+ 命中清单

## 🟣 工具 Tools

### 🔗 链接提取（links）

- **输入**：目标 URL
- **能力**：从页面 HTML + JS 提取全部 URL / 接口路径
- **输出**：去重链接清单，可 handoff 到 URL 多开 / 目录扫描

### 📑 URL 多开（url 多开）

- **输入**：URL 列表（每行一个）
- **能力**：批量在新标签页打开；接入 `TaskController` 可取消
- **用途**：批量验证、配合链接提取 / 目录扫描结果

### 📜 历史档案（history）

- **能力**：扫描历史记录（按时间 / 类型 / 目标检索）；从历史 **回跳** 到对应面板继续分析
- **特点**：写放大优化，同窗结果合并

### 🗂️ Wayback（history-archive）

- **输入**：目标 URL
- **能力**：查询网页历史存档（Wayback Machine 等）
- **输出**：历史快照列表，可 handoff

### 📑 标签保存（tabsave）

- **能力**：保存当前所有打开的标签页为会话，随时恢复
- **输出**：会话文件（可导出）

### 📷 EXIF 查看（exif）

- **输入**：图片 URL / 文件
- **能力**：读取图片 EXIF 元数据（相机型号 / 拍摄时间 / GPS 定位）
- **输出**：元数据清单（含地图坐标，可复制）

### 🗄️ 存储检查（storage-check）

- **输入**：目标 URL
- **能力**：读取并审计页面客户端存储
  - localStorage / sessionStorage（键值）
  - IndexedDB（库 / 表 / 记录）
  - Cookie
- **用途**：发现存储中的 Token / 用户信息 / 调试数据
- **输出**：分类存储清单

### 📦 源码加载（source-loader）

- **输入**：目标 URL
- **能力**：获取页面源码（HTML）
- **输出**：源码文本（可导出）

### 🗜️ JS 归档（jsarchive）

- **输入**：目标 URL
- **能力**：抓取页面所有 JS 资源，打包成 ZIP 下载
- **任务控制**：接入 `TaskController`，可取消
- **预算**：累计 100 MB 上限；MANIFEST 仅记 url / path / size / status，不记录 Cookie / Authorization
- **输出**：ZIP（含 MANIFEST 索引）

## ⚪ 报告 Report

### 📊 统一报告（report）

- **能力**：汇总各面板扫描结果，生成统一报告
- **脱敏**：报告中敏感信息自动脱敏（Token / Cookie / API Key → `***REDACTED***`，手机号 / 身份证 / 姓名 / 邮箱按规则脱敏）
- **输出**：可导出（支持筛选 / 统计）

## 设置

打开方式：浏览器扩展管理页 → 灵眸 → 选项（或 `options.html`）

| 项 | 说明 |
|---|---|
| 测绘平台 API Key | FOFA / ZoomEye / Quake 等，供资产测绘 / 子域名调用 |
| 限流配置 | 按 hostname 的请求速率上限（控制测试强度，防 DoS） |
| HaE 自定义规则 | YAML 编辑自定义规则组，支持恢复默认 |
| 主题 | 浅色 / 深色（跟随系统） |

> API Key 存于 `storage.local`，不写日志、不进下载归档、不上报。

## 常见问题

**Q：和 Burp Suite 是什么关系？**
A：互补。Burp 是流量代理（抓包 / 改包 / 重放 / Intruder），灵眸是浏览器内“页面侧”分析工具（框架运行时 / JS 提取 / 泄露扫描）。实战中常配合使用：Burp 管流量，灵眸做页面深度分析。

**Q：为什么没有抓包重放？**
A：浏览器扩展架构上无法做全流量代理。这是定位选择，不是缺失——重放交给 Burp / ZAP / Caido。

**Q：为什么需要 `<all_urls>` 权限？**
A：content script 注入、Cookie 审计、JS 归档、框架分析需要在用户打开面板时（未必点过图标）访问页面。已通过 url-guard + sender-guard 双重门控收敛风险。详见 [权限矩阵](权限矩阵.md)。

**Q：数据会上传服务器吗？**
A：不会。除调用用户配置的外部测绘 API（FOFA / ZoomEye 等）外，所有数据本地处理；无任何自动外传。
