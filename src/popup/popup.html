RuoYi 路由

        
RuoYi 后台管理系统的路由分析与权限测试工具。发现被权限系统隐藏的菜单和接口。

        

          ① 检测
          ›
          ② 拦截
          ›
          ③ 发现隐藏路由
          ›
          ④ 探测验证
        

        

          
          
          
          
          
          
        


        
        

          

            
识别目标系统

            
检测当前页面是否使用 RuoYi 框架，识别版本号和变体（Vue2 前后端分离 / Vue3 / Thymeleaf 模板 / 微服务版本）。这是所有后续操作的前提。

          

          

            
          

          

          

            
打开 RuoYi 系统页面后，点击「检测 RuoYi」识别框架

          

        


        
        

          

            
拦截路由数据 需要先检测框架

            
注入脚本拦截 /getRouters 接口响应，获取当前用户被授权的完整菜单路由树。需要登录后操作。支持增强模式自动注入额外路由。

          

          

            
            
            
          

          

            
            
          

          

            
            
          

          
未安装

          

            
安装钩子后登录并刷新页面，或点击「检查状态」查看捕获结果

          

          

            
            
            
          

        


        
        

          

            
发现隐藏路由 需要先检测框架

            
通过扫描 JS 源码和 RuoYi 标准路由字典（35条），发现被权限系统过滤掉的隐藏菜单路由。找到后可一键注入 Vue Router 直接访问，或复制 URL 手动测试。对非 Vue 应用（Thymeleaf）自动切换为 URL 模式。

          

          

            
            
            
            
          

          

          

            
先「检测 RuoYi」确认框架，再点击「扫描动态路由」查找隐藏菜单

          

        


        
        

          

            
深度分析 JS 路由 需要先检测框架

            
扫描页面所有 JS 文件中的路由定义（path / component / meta），对比已注册路由找出额外的路由入口。适合发现开发者自定义的、未在标准菜单中注册的路由。

          

          

            
            
            
          

          

            
            
          

          

          

            
先「检测 RuoYi」确认框架，再点击「分析JS路由」深度扫描

          

        


        
        

          

            
批量请求探测 需要先发现路由

            
对已发现的路由路径逐个发送 HTTP 请求，根据状态码判断：200 可访问 / 301-302 重定向 / 401 未授权 / 403 禁止 / 404 不存在。快速定位可越权访问的隐藏接口。

          

          

            
            
          

          

            
            
            
            
            
            
            
          

          

          

          

            
先通过「动态路由」或「JS分析」发现路径，再在此处批量探测

          

          

            
          

        


        
        

          

            
API 请求监控 需要先安装钩子

            
被动监控浏览过程中的所有 API 请求，记录请求方法、URL、状态码和响应内容。可用于发现隐藏接口、分析参数和敏感数据泄露。

          

          

            
            
            
          

          

            
          

          

          

            
先在「路由钩子」中安装钩子，浏览页面后点击「加载流量」查看

          

        

      

    

  

    编码工具
